# CS172 Computer Vision

This repository contains coursework for CS172 Computer Vision. Each homework is kept in its own `HWx/` directory so that source code, reports, experiments, and homework-specific instructions stay together.

## Homework

### HW1 - CAPTCHA Recognition

`HW1/` contains the CAPTCHA recognition assignment. The work covers synthetic five-digit CAPTCHA generation, PyTorch dataset and preprocessing design, ResNet-based recognition, training and checkpointing, evaluation on held-out test sets, and controlled ablation experiments.

The assignment specification is in [`HW1/INSTRUCTION.md`](HW1/INSTRUCTION.md), and the experiment report template is [`HW1/main.ipynb`](HW1/main.ipynb).

### Adding future homework

Create a new `HW2/`, `HW3/`, and so on. Add a short description under this section and keep the corresponding code, report, and instructions inside that homework directory.
